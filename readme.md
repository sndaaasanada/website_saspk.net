# saspk.net

個人サイト「saspk.net」のソースコードです。HTML・CSS・JavaScriptで作成しています。

## ページ

- **目次** (`index.html`): サイト内のページへのリンク
- **無線** (`musen/`): 無線に関するページ
- **日記** (`diarie/`): 日々の記録
- **数学** (`maths/`): 数学に関するページ

## 表示方法

`index.html` をブラウザーで開くか、Visual Studio Code の Live Server などを使って表示してください。

## 主なファイル

- `default.css`, `style.css`: サイトのスタイル
- `script.js`: ページ上の動作
- `content.json`, `musen.json`, `diarie.json`: ページ表示用のデータ
